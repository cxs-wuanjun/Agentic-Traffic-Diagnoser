# 合规预案 (Compliance SOP) 技能手册

在撰写最终报告的“处置建议”环节，你不能自行编造建议，必须严格引用官方预案库中的原文。

## 操作指南
当前技能包内提供了一个 JSON 数据库 `agent/skills/compliance-sop/resources/database.json`。
当你在分析报告中判定了当前的交通异常类型（例如“拥堵”、“事故”、“施工”），你应该在你的 Python 绘图或排版代码中，读取这个 JSON 文件，把对应的官方预案提取出来，并直接插入到你的最终 Word 文档中，作为“附录”。

## 数据格式
JSON 文件是一个字典映射：`{"事故": "预案内容...", "施工": "预案内容..."}`。如果未找到匹配类型，请默认使用 `拥堵` 的预案。
